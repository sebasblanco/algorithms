# Algorithms

A collection of algorithm implementations across data science, machine learning, and quantum computing — built in Python and Jupyter Notebooks.

## Data Science

| Notebook | Description |
|---|---|
| `greedy.ipynb` | Greedy algorithm for optimization problems |
| `montecarlo/` | Monte Carlo simulation with data preprocessing |
| `regressions/interpolated_polynomials.ipynb` | Linear vs quadratic regression comparison |
| `regressions/insurance-dataset/` | Regression with scikit-learn on insurance data |
| `regressions/fred-dataset/economics.ipynb` | Linear regression on FRED economic data (interest rates vs unemployment) |

## Machine Learning

| Notebook | Description |
|---|---|
| `clustering/iris-dataset/knn_classification.ipynb` | k-Nearest Neighbors classifier on Iris dataset |
| `clustering/iris-dataset/ann_classification.ipynb` | Artificial Neural Network classifier on Iris dataset |
| `clustering/insurance-dataset/kmeans.ipynb` | k-Means clustering on insurance data |
| `sentiment-analysis/election_tweets.ipynb` | NLP sentiment analysis on 2020 election tweets |
| `home-price-prediction/dtft-prediction.ipynb` | Random Forest model for home price prediction |

## Quantum Computing

| Notebook | Description |
|---|---|
| `Bernstein-Vazirani.ipynb` | Bernstein-Vazirani algorithm to determine a hidden binary string |
| `Hamiltonian.ipynb` | Hamiltonian simulation to find optimal quantum state |

## Stack

Python · Jupyter · scikit-learn · NumPy · Pandas · Qiskit
